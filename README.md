# 情绪小树林

一个给情绪留出口的网页小工具：先用小游戏把情绪放出去一点，再慢慢把话讲清楚。
纯静态 HTML / CSS / JavaScript，无依赖、无构建步骤，双击即可打开。

## 打开方式

直接双击 `情绪小树林-手机版.html`（建议用 Chrome / Edge / Safari 打开，手机浏览器也可）。

页面按手机尺寸设计，桌面浏览器里会以手机卡片的形式居中显示。

## 页面结构

- **想聊聊**：写下此刻的心情，进入「情绪搭子」对话；也可语音输入
- **要宣泄**：五种释放方式，其中三个是独立小游戏
  - 火把融冰（`火把融冰-解压小游戏.html`）
  - 乌云小风扇（`乌云小风扇.html`）
  - 今天不吃饼 · 节拍呐喊（`节拍呐喊-小游戏.html`）
- **想清楚**：沿着刚才的话，一步步梳理感受和下一步
- **我的情绪树**：左右滑动查看五个成长阶段，经验值随等级变化
- **档案 / 成就**：记录疗愈过程与解锁的徽章

## 关于 AI 对话

默认使用内置的本地回复，不联网也能跑。
若要接入大模型，把 `window.EMOTION_AI_ENDPOINT` 指向你自己的同源后端接口即可，
请求体为 `{ messages, context }`，返回 `{ reply }` 或 OpenAI 风格 `choices[0].message.content`。
**请把模型密钥留在服务端，不要写进前端页面。**
